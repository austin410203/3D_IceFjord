# 3D 渲染技巧清單：Minamo × Pond Line

研究日期：2026-10-25
- **Minamo**（水面）：https://github.com/kanaworksai-hue/minamo — MIT 授權，素材 CC0。海面、水下、半水面的即時水體算圖。
- **Pond Line**（金魚電車）：https://pondline.scottsun.io — 淹水的電車車廂，裡面有花、藤蔓和金魚。單一 HTML 檔，約 2,700 行。

兩者都用 **three.js r186 + `WebGPURenderer` + TSL**。Minamo 另外寫了 WGSL compute shader。

---

## 一、共通的底層心法（最值得學）

| # | 心法 | Minamo 怎麼做 | Pond Line 怎麼做 |
|---|---|---|---|
| 1 | **全部用真實公尺單位** | 浪高、焦散窗口 20 m、岩石 LOD | 座椅高 0.47 m、行李架 1.80 m、水深 0.30 m |
| 2 | **用真實物理係數，不憑感覺調色** | 熱帶海水 RGB 吸收/散射係數（Jerlov IA–IB），出自論文 | 「略帶藻類的池水」吸收/散射係數、水的折射率 1.333 |
| 3 | **對著參考圖校準** | 視覺目標：William Faucher 的 UE EasyWaterscape | 註解一直出現「calibrated to the reference」「as in the reference」 |
| 4 | **好看比物理正確優先（藝術指導）** | 鏡頭貼著浪漂，讓水線一直掃過畫面 | 車頂不投影、改用樹葉形遮罩，做出斑駁陽光；顏色先預補償藍色玻璃和調色的偏色 |
| 5 | **同一個函式算到底** | 水面網格和逐像素水線檢測共用同一個浪高函式，水線才不會鋸齒 | 水面和焦散共用同一組波浪 |
| 6 | **到處都有細微動態** | 漂浮鏡頭、9,000 顆海雪粒子、鏡頭水膜流下 | 陣風沿走道傳過去、每株植物有自己的相位、金魚游動、花瓣漂浮 |
| 7 | **最後一定做後製調色** | Bloom → 自動曝光 → AgX → 暗角 → 底片顆粒 | 色差 → 暖色 Bloom → 白平衡 → 飽和度 → 分離色調 → S 曲線 → 暗角 |

## 二、光線與環境

| 技巧 | 出處 | 說明 / 參數 |
|---|---|---|
| **把太陽從 HDRI 抽成平行光** | Minamo `world.js` | 在 HDRI 裡找最亮的區塊，積分成照度，再把太陽像素換成周圍的天空亮度。天空負責環境光，平行光負責銳利陰影，兩者不重複計算 |
| HDRI 用 EXR 並預先縮放 | Minamo | 太陽亮度超過 half-float 上限，所以存成 radiance/2，載入時再還原 |
| 高解析度柔和陰影 | Minamo | `PCFSoftShadowMap`，`mapSize` 4096 |
| **只用粗模投影** | Minamo | 高模只負責顯示，另一份低模放在 layer 1 專門投影 |
| 陰影視錐貼合場景 | Pond Line | 陰影相機剛好框住車廂 |
| **自製 Light Probe（cube capture）** | Pond Line | 先拍天空 cube 給海用，再拍車廂內部 cube 當室內 envMap（強度 0.25–0.6） |
| 補回 probe 漏掉的反彈光 | Pond Line | probe 看不到水，所以天花板的 envMapIntensity 手動調高，補回水面反彈上去的光 |
| 藝術化的反彈光 | Pond Line | 上方暖奶油色、下方水面薄荷綠，兩盞補光 |
| 斑駁陽光 | Pond Line | 車頂排除在陰影之外，改用樹葉形遮罩當陰影 |
| AO 預算圖 | Pond Line | 玻璃等透明物件放在 layer 1，不進 AO 預算圖，以免產生髒污 |

## 三、水

| 技巧 | 出處 | 說明 |
|---|---|---|
| **FFT 海洋（Tessendorf）** | Minamo | JONSWAP 頻譜 + 方向擴散 + 獨立湧浪，3 層 cascade（250 m / 37 m / 7.3 m，各 256²） |
| Jacobian 白沫 | Minamo | 用位移場的 Jacobian 判斷浪尖擠壓處，在那裡生成白沫 |
| 分析式小波束 | Pond Line | 能量集中在 10–35 cm 的漣漪，剛好在水下約 30 cm 聚成焦散網 |
| **依像素足跡淡化波浪** | 兩者 | 遠處無法解析的細浪漸漸淡掉，遠方水面才不會閃爍 |
| 精確 Fresnel + GGX 太陽高光 | Minamo | 從上往下看的水面 |
| 螢幕空間折射 | 兩者 | 法線偏移有上限；Pond Line 會檢查折射採樣點是否真的在水面下，避免把水上的亮牆拉進水裡 |
| **平面反射 + 波浪擾動 + 失效回退** | Pond Line | 鏡面比水面低幾毫米；擾動後如果採到天空，就退回未擾動的結果 |
| 先畫背面再畫正面 | Minamo | 隔著浪尖看浪尖時，仍有玻璃般的通透感 |
| 浪尖次表面散射 | Minamo | 浪尖透光發亮 |
| **Beer–Lambert 吸收（RGB 分開算）** | 兩者 | 紅光最先被吸收，水越深越藍綠 |
| 單次散射的解析解 + HG 相位函數 | Minamo | 0.85·HG(0.9) + 0.15·HG(0.2)，強烈前向散射 |
| **焦散：面積比法** | 兩者 | 源自 Evan Wallace 的 WebGL Water：把網格經水面折射後投到地面，三角形縮小的地方就變亮 |
| 焦散色散 | Minamo | 用 3 個折射率畫 3 次 |
| 焦散景深模糊 | Minamo | 用 mipmap，越深越模糊 |
| 天光焦散 | Pond Line | 窗外天空是面光源，焦散要依光源角度大小做模糊 |
| 水下光柱 | Minamo | 沿視線 ray-march 焦散，半解析度計算，再用考慮深度和介質的雙邊濾波放大 |
| Snell 窗 + 全反射 | Minamo | 從水下往上看 |
| **所有材質統一「水下化」** | Minamo `underwaterize()` | 每個不透明材質都套用同一套水下光照：衰減、焦散、天光色偏 |
| **濕潤帶** | Minamo | 水線上方約 0.7 m，用噪聲決定邊緣，albedo ×0.55、roughness ×0.35 |
| 鏡頭水效果 | Minamo | 半月面、排水水膜模擬、水珠、會滑動合併的水滴 |

## 四、幾何與模型

| 技巧 | 出處 | 說明 |
|---|---|---|
| **零模型，全部程序化** | Pond Line | 平行傳輸的管線（扶手、藤莖）、超橢圓截面掃掠、圓角多邊形、倒角折線 |
| **到處都有倒角和圓角** | Pond Line | 椅墊有拱起和接縫凹陷、壓紋裙邊、縫線溝。CG 感常來自完全銳利的直角邊 |
| 貼花浮出牆面 3 mm + depth bias | Pond Line | 防止 z-fighting |
| 掃描模型 + 自動 LOD | Minamo | Poly Haven CC0 掃描岩石，用 meshoptimizer 產生 lod0..n，依「投影誤差 < 0.75 px」切換 |
| 素材建置管線 | Minamo | `fetch_assets.py` 下載 Poly Haven → `build_assets.mjs` 產生 LOD、meshopt 壓縮、WebP 貼圖 |
| 岩石半埋進沙裡 | Minamo | 讓它看起來是露頭，而不是擺在地上的方塊 |
| 地形用 fbm 噪聲 | Minamo | 沙丘、沙洲、礁台；兩種沙地材質以巨觀尺度混合 |
| 固定種子亂數 | Pond Line | `mulberry32(7)`，每次產生的結果都一樣，方便調整 |

## 五、植物與生物（Pond Line）

| 技巧 | 說明 |
|---|---|
| 程序化生長的藤蔓 | `growHanging`：重力 + 隨機漫遊 + 碰撞限制，每節 1–3 片葉子，偶爾長出側芽，看起來才「蓬」而不像串珠 |
| 葉片 instancing + 彎曲法線 | 平面葉片的法線往兩側傾斜，打光時看起來像彎曲的曲面 |
| 花頭分成 3 種 | 花瓣型、聚繖花序（馬纓丹/九重葛）、絨球型 |
| **成片種植 + 多層堆疊** | 品種每約 25 cm 換一片，加上小白花填縫、葉片底層、溢出座椅邊緣、掉落的花瓣 |
| 陣風 | 陣風鋒面沿走道傳遞，相鄰植物一起傾斜，再疊上各自的抖動 |
| 程序化金魚 | 身體、分叉的皺褶尾鰭、交錯排列的鱗片，加上漫遊、留在走道內、活動範圍等行為 |
| 2.5D 積雲 | 方位角/仰角上的密度場 + 域扭曲做出花椰菜狀邊緣 + Beer–Lambert + 3 點自陰影 |

## 六、後製與調色

| 步驟 | Minamo | Pond Line |
|---|---|---|
| 抗鋸齒 | 1.25× 超取樣（不用 TAA） | MSAA 4×，像素比上限 1.5 |
| 色差 | — | 0.0016 |
| Bloom | 13-tap 降採樣 / tent 升採樣，0.035 | `bloom(hdr, 0.16, 0.6, 0.85)`，再乘暖色做光暈 |
| 曝光 | 自動曝光（對數平均亮度，隨時間適應） | 固定 0.88 |
| 色調映射 | **AgX** | Neutral |
| 調色 | — | 白平衡 (1.17, 0.93, 0.8)、飽和度 1.25、**亮部偏金、暗部偏青的分離色調**、38% S 曲線 |
| 暗角 / 顆粒 | 0.25 / 0.012 | 0.2 / — |
| HDR 防呆 | 材質輸出先 clamp；後製一開始就清掉 NaN/Inf | — |

## 七、工程與體驗

| 技巧 | 出處 |
|---|---|
| 畫質預設 `?quality=high/medium/low`，所有參數都能用 URL 覆寫 | Minamo |
| 按 P 顯示逐 pass 的 GPU 時間（timestamp query） | Minamo |
| 不在材質裡用 viewport 節點（會強制複製整張畫面），改成自己複製一次背景 | Minamo |
| **載入畫面後先預熱所有 pipeline**，進場才不會卡頓 | Pond Line |
| 運鏡：Minamo 有 37 秒示範路徑；Pond Line 有 5 個運鏡鏡頭，按 C 切換 | 兩者 |
| 環境音（池塘），處理行動裝置的音訊解鎖 | Pond Line |
| 第一人稱漫遊 + 碰撞（沿著障礙物滑動） | Pond Line |

## 八、可以直接寫進 prompt 的要求

```
技術：three.js r186 WebGPURenderer + TSL（需要時加 WGSL compute），單位一律用公尺。
光線：HDRI(EXR) 當環境光，並把太陽抽成平行光；陰影 4096 PCFSoft，只讓粗模投影；
      室內場景要拍 cube light probe，再手動補反彈光。
材質：用真實物理係數（水、玻璃、金屬）；水線上方要有濕潤帶；所有物件都要倒角，不能有銳利直角邊。
細節：植物要多層堆疊（底層葉、主花、填縫小花、溢出、落葉）；全部加上陣風搖擺。
水：Beer–Lambert RGB 吸收 + 面積比焦散 + 依像素足跡淡化波浪 + 折射採樣檢查。
後製：MSAA 或超取樣 → 暖色 Bloom → AgX/Neutral → 白平衡 → 分離色調 → S 曲線 → 暗角 → 顆粒。
工程：固定種子亂數、畫質預設、URL 參數、pipeline 預熱、GPU 計時面板。
流程：每個階段截圖並和參考圖比對，列出 3 個最大差異後修正。
```
